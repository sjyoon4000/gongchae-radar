# 공채레이더 V10 — 자동 시세 갱신 오류 수정본

## 수정 사항
- 자동수집 저장 경로를 `www/data.json`으로 수정. GitHub Actions 커밋 경로도 동일하게 수정.
- 2026년 9월 하드코딩 시세를 화면 코드에서 제거. 앱 시작 시 서버 연결 전에는 수치를 표시하지 않음.
- 앱 내장 초기 자료는 사용자 제공 Cartok 화면의 **2026-10-29** 수치이며, **자동수집 성공 데이터가 아님**을 구분 표시.
- 서버 JSON의 날짜/시세/지역 데이터 검증 및 조회 실패 안내.
- 광고 하단 공간 유지, 광고 SDK는 아직 미설치.

## 실제 자동 업데이트를 켜는 절차
1. 이 프로젝트를 GitHub 공개 저장소에 올립니다. GitHub Actions 쓰기 권한을 설정합니다.
2. Actions → `Cartok 공채시세 갱신` → `Run workflow`로 수동 실행하고 **성공 로그와 `www/data.json`의 `verifiedAutomated: true`를 확인**합니다.
3. 웹 호스팅(GitHub Pages 등)에서 `www/data.json`을 HTTPS로 제공하고 `www/app-config.json`의 `dataUrl`에 **실제 공개 주소**를 넣습니다. URL을 모르는 상태에서 임의의 주소를 채워 넣지 않았습니다.
4. Android 앱을 다시 빌드해 기기에서 네트워크 새로고침과 날짜 표시를 확인합니다.
5. 수집 실패하면 Actions가 실패로 기록되고 이전 날짜가 유지됩니다. 사이트 차단/HTML 구조 변경은 별도 조치가 필요합니다.

## 출시 전 필수 확인
- Cartok 원본은 이 제작 환경에서 접속 불가하여 **실제 수집 성공을 검증하지 못했습니다**.
- 전국 17개 시·도 매입률 및 감면 규정은 공식 검증 미완료. 견적 확정에 사용하지 마세요.
- Android Studio 빌드, 실기기 테스트, Google Play 서명·심사 미완료.
- 앱 설치 후 자동 갱신에는 배포된 HTTPS 데이터 서버가 필수입니다.
